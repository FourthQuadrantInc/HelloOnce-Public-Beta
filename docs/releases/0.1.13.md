# Friend 0.1.13

Friend 0.1.13 is the first public release since 0.1.9. It brings everything from the 0.1.10–0.1.12.1 team previews, a new data layer (originals first, records with their sources, My Data Wallet for agents), this Mac's sources, speaker-aware recordings and QR pairing for devices.

**This release is macOS (Apple Silicon) only. Linux and Windows stay on 0.1.9 for now; their in-app updater reports no package for this version.**

## What's new

- **My Data Wallet for agents** — one MCP server, `my-data-wallet`: `data_catalog`, `data_search` (a short question table), `data_get`, `data_handoff`.
- **Originals first** — every file, message and event kept once, each fact pointing to where it came from; HEIC/AVIF, Office/iWork and mail read.
- **This Mac's sources** (off until you turn each on) — Photos, Voice Memos, Calendar, Reminders, Notes, Safari, calls, iMessage and WhatsApp.
- **Recordings** tell speakers apart and recognise you (with a diarizing speech model); long recordings are read in parallel parts.
- **QR pairing** — an app on another device becomes a personal connection that sends text and files through the encrypted relay.
- **Faster processing** — 16 jobs at a time by default (8 with audio or pictures); what happened in the last 24 hours goes first; the same file is read once.
- **New interface by default**; the classic one is at `/classic`. Signing in once stays valid.

## Upgrading

Back up first (the in-app updater does it for you). The data directory is migrated on first start. Agent chats captured by 0.1.8/0.1.9 return to search after they are re-read by conversation window, which needs a configured model.

## Known limits

- friend.'s helper app on the Mac is not yet signed with a Developer ID: macOS asks for its permissions again after each update.
- The new interface is still a preview.

## Install

Download `openworld-memory-v0.1.13-macos-arm64.tar.gz` below, or verify `install.py` against `SHA256SUMS` and run:

```sh
python3 install.py --version v0.1.13 --clients codex,claude --start --autostart
```

0.1.8 and later can update from Settings → Personal memory library → Software updates. Only configure the clients you use.
