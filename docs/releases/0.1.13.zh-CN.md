# Friend 0.1.13

自 0.1.9 以来的第一个公开版本：包含 0.1.10–0.1.12.1 团队预览版的全部内容、新的数据层（先存原件、记录带来源、给 agent 的“数据钱包”）、这台 Mac 上的来源、能分说话人的录音，以及扫码配对设备。

**本版只提供 macOS（Apple 芯片）安装包。Linux 和 Windows 暂时停在 0.1.9，应用内更新会提示该版本没有对应安装包。**

## 新内容

- 给 agent 的数据钱包：统一的 MCP 服务 `my-data-wallet`，按需求场景列出有什么，按提问表给值和证据。
- 先存原件：每条事实指回原件中的位置；新增 HEIC/AVIF、Office/iWork、邮件等格式。
- 这台 Mac 上的来源（每项默认关闭）：照片、语音备忘录、日历、提醒事项、备忘录、Safari、通话、iMessage 和 WhatsApp。
- 录音可分说话人并认出你（需能分说话人的语音模型）；长录音分段并行处理。
- 扫码配对：其他设备上的 App 成为个人连接，经加密中转发送文字和文件。
- 处理更快：默认同时 16 个作业（音频/图片 8 个）；最近 24 小时的先处理；同一份文件只读一次。
- 默认使用新界面，经典界面在 `/classic`；登录一次长期有效。

## 升级

先备份（应用内更新会自动备份）。首次启动时迁移数据目录。0.1.8/0.1.9 采集的 agent 聊天需要按对话窗口重新理解（需已配置模型）后才回到检索结果。

## 已知限制

- Mac 上的小助手 App 还没有 Developer ID 签名，每次更新后 macOS 会重新请求权限。
- 新界面仍是预览。

## 安装

下载下方的 `openworld-memory-v0.1.13-macos-arm64.tar.gz`，或用 `SHA256SUMS` 校验 `install.py` 后运行：

```sh
python3 install.py --version v0.1.13 --clients codex,claude --start --autostart
```
