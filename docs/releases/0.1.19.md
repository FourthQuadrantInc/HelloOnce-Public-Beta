# HelloOnce 0.1.19

A new home and a new connections page, a first run that sets itself up, and agents that can follow what changed.
Includes everything since 0.1.18.

## First run

- **Install from any agent.** Paste the short prompt from the README into the agent you use; it installs HelloOnce,
  connects **itself** only, and opens HelloOnce in your browser.
- **Get started** on the home page: let your assistants use HelloOnce (the others found on this computer are listed;
  one click connects each and **opens its app**: an app that was already open is restarted by you once), add a
  source, and tell HelloOnce which names are yours.
- **Every source starts with the last three months.** The source's ··· menu offers *Organize the past year* or
  *Organize everything*; Photos says how many older photos wait. A range you chose yourself is kept.

## Home and connections

- The home page is about you: your confirmed name and a one-line summary, what still waits for your answer (one
  line each, most urgent first), an overview by day, week or month, and the newest records.
- Connections has two pages, **Sources** and **Agents**, and a table of everything connected. Public platforms are
  grouped by what they are for; every source on this computer or your phone opens the same detail window: what it
  reads, what it never reads, and its own ledger.
- When something is wrong the button says **Retry** and goes where the fix is (System Settings, a new sign-in, a new
  read). Items that failed to be organized can be organized again in one click.
- Breadcrumbs everywhere; "Ledger" is called **Records**; three text sizes (16 / 18 / 20, default 18).
- The account page links to where redemption codes are sold.

## For agents

- **`data_changes`**: the keys that changed since a cursor, so an agent that works between conversations (a morning
  brief, a follow-up tracker) knows what to read again. HelloOnce still never speaks first.
- An agent can correct or withdraw what it reported itself; others see it only after you confirm it in
  Settings.
- Old conversations can be picked up again across days by naming their project.

## Organizing

- Newest first: history is organized from the most recent backwards, and an older item can never overwrite a newer
  one. Event pages are written in parallel.

## Your Android phone

- The HelloOnce Android app 2.0 needs no root. It pairs by QR code under Connections → Personal and sends the kinds
  you turn on in it: contacts, calendar, text messages, call log, photos and videos, voice recordings, a folder,
  notifications, places, app usage and Health Connect. Each arrives as its own kind of record, and the phone's page
  lists the Android kinds: what has arrived, and where to turn on the rest.

## Windows

- Computer history and Chrome / Edge browsing history are read on Windows; the connections pages show only what a
  Windows computer has; agent hooks run in every shell. This release ships a Windows package; Linux follows once
  its tests pass.

## Upgrading

The data files take their new names on first start (`data.sqlite3`, `ledger.sqlite3`): only names change, nothing is
rewritten. The command is `helloonce`; `openworld-memory` keeps working. Sources already on keep their range.
