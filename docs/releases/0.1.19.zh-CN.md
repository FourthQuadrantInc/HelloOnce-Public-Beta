# HelloOnce 0.1.19

新的首页和连接页、装好就能上手的第一次使用，以及 agent 能跟上"什么变了"。包含 0.1.18 之后的全部改动。

## 第一次使用

- **从任何 agent 安装。** 把 README 里的短提示词贴给你在用的 agent：它装好 HelloOnce、只把**自己**接上，然后在浏览器里打开
  HelloOnce。
- 首页的**开始使用**：让你的 Agent 用上 HelloOnce（列出这台电脑上找到的其他 Agent，点一下就接上并**打开它的 App**；本来开着的
  需要你重启一次）、加一个来源、告诉 HelloOnce 哪些名字是你。
- **每个来源第一次只整理最近三个月。** 来源的 ··· 菜单里有「整理近一年」「整理全部」，照片会显示还有多少张更早的。你自己设过的范围
  不会被改。

## 首页和连接页

- 首页讲的是你：已确认的名字和一行身份摘要、还等你决定的事（一件一行，急的在前）、按日 / 周 / 月看的概览、最近的记录。
- 连接分**来源**和 **Agents** 两页，另有全部已连接的总表。公共平台按用途分组；本机和手机上的每个来源都能打开同一种详情浮窗：
  能读什么、不会读什么、它自己的记录。
- 出问题时按钮叫**重试**，点了直接去解决的地方（系统设置、重新登录、重新读取）；整理失败的数据可以一键重新整理。
- 全站面包屑；「流水」改叫**记录**；字号三档 16 / 18 / 20，默认 18。
- 账号页可以直接去买兑换码。

## 给 agent

- **`data_changes`**：从某个游标起变过的 key，让在对话之外持续工作的 agent（早报、跟进提醒）知道该重读什么。HelloOnce 仍然不会
  主动开口。
- agent 可以更正、撤回自己提交的记录；在设置里确认之前，别的 agent 看不到。
- 点名项目就能跨天接上以前的对话。

## 整理

- 最新的先整理：历史倒着整理，旧的内容不会覆盖新的；事件页并行写。

## 安卓手机

- HelloOnce Android App 2.0 不再需要 root：在「连接 → 个人」里扫码配对，同步你在 App 里打开的类别：通讯录、日历、短信、通话记录、
  照片和视频、录音、一个文件夹、通知、到访地点、应用使用时间和 Health Connect。每一类都存成对应种类的记录；手机页列出安卓的
  各类数据：哪些已经收到，其余的去哪里打开。

## Windows

- Windows 上能读电脑记录和 Chrome / Edge 浏览记录；连接页只显示 Windows 电脑有的来源；agent 钩子在各种 shell 里都能跑。
  本版提供 Windows 安装包；Linux 安装包等平台测试通过后再发。

## 升级

第一次启动时数据文件换成新名字（`data.sqlite3`、`ledger.sqlite3`），只改名、不改内容。命令是 `helloonce`，
`openworld-memory` 仍可用。已经开着的来源保持原来的范围。
