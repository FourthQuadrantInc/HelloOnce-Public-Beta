# HelloOnce 0.1.20

HelloOnce 0.1.20 gives the macOS (Apple Silicon) and Windows (x64) public packages a new shared version number. An installed copy of 0.1.19 can now detect 0.1.20 as an update. Both packages use the same application code as the final 0.1.19 public build.

Open **Settings → General → Software updates** to update an existing installation. For a new installation, download `install.py` and `SHA256SUMS` from the [0.1.20 public release](https://github.com/FourthQuadrantInc/HelloOnce-Public-Beta/releases/tag/v0.1.20). To select this version explicitly, pass `--version v0.1.20` to the installer.
