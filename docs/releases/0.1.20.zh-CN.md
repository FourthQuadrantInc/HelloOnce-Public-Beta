# HelloOnce 0.1.20

HelloOnce 0.1.20 为 macOS（Apple Silicon）和 Windows（x64）公测包启用同一个新版本号。已安装的 0.1.19 可以检测到 0.1.20 更新。两个平台沿用 0.1.19 最终公测包的应用代码。

已有用户可在设置里的「软件更新」检查新版本。首次安装请从 [0.1.20 公测发布页](https://github.com/FourthQuadrantInc/HelloOnce-Public-Beta/releases/tag/v0.1.20) 下载 `install.py` 和 `SHA256SUMS`。要指定这个版本，请给安装器传入 `--version v0.1.20`。
