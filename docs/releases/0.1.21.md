# HelloOnce 0.1.21

Four more agents send their conversations back, a first chat import that finishes in a sitting, and this Mac's sources
that recover once a permission is given. Includes everything since 0.1.20.

## Conversations from your agents

- **Four more agents send their conversations back** to HelloOnce, read from the records each keeps on this computer:
  Antigravity, Cursor, WorkBuddy / CodeBuddy and Gemini CLI, besides Codex and Claude Code. Connecting one brings in
  its last three months.
- **Seven more agents can be connected** from the Agents page: OpenClaw, OpenCode, Antigravity CLI (`agy`), Kimi Code
  CLI, GitHub Copilot CLI, Cherry Studio and TRAE CN. They do not send conversations back yet, and the page says so
  instead of promising it.
- An agent registered under a name that matches a known one is treated as that agent only after you confirm it:
  HelloOnce does not trust a name an agent gives itself.
- **The first import is much faster.** Months of conversations are organized in parallel and continuously until they
  are done, instead of twenty pieces every ten minutes; deleting something during the import takes effect at once.

## This Mac

- **Retry really retries.** Items that had failed are organized again from where they were, iMessage is no longer
  held up by one empty message, and a failure because the account ran out of balance says so.
- **Permissions.** Retry opens System Settings at the right list (on macOS 27 too) and shows the steps to add
  HelloOnce. Once you give a permission, every source waiting for it reconnects and its warning goes away by itself;
  Accessibility is no longer asked twice. If HelloOnce's helper does not answer, the button still opens System
  Settings, and when HelloOnce itself does not respond the page says that instead of blaming System Settings.
- **Computer history is written ahead.** The page no longer shows every period as "organizing" when you open it.
- **Add a phone** shows the iPhone and Android apps side by side, each with its QR code and link.

## Reliability

- Long model calls no longer hold the database: agents reading HelloOnce (for example a personal agent checking in
  every 15 minutes) no longer fail with "database is locked" at start-up.
- Events from different days that belong to the same project or course are linked into one.

## Updating

Open **Settings → General → Software updates** to update an existing installation. For a new installation, download
`install.py` and `SHA256SUMS` from the [0.1.21 public release](https://github.com/FourthQuadrantInc/HelloOnce-Public-Beta/releases/tag/v0.1.21).
To select this version explicitly, pass `--version v0.1.21` to the installer.
