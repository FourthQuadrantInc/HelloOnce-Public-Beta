# HelloOnce 0.1.21

又有四个 agent 能把聊天回传，第一次导入聊天不用再等几个小时，本机来源给了权限就能接上。包含 0.1.20 之后的全部改动。

## Agent 聊天回传

- 除了 Codex 和 Claude Code，又有**四个 agent 能把聊天回传**给 HelloOnce（读的是它们在这台电脑上自己留的记录）：Antigravity、
  Cursor、WorkBuddy / CodeBuddy 和 Gemini CLI。接上时补回最近三个月。
- 又有**七个 agent 可以在 Agents 页接上**：OpenClaw、OpenCode、Antigravity CLI（`agy`）、Kimi Code CLI、GitHub Copilot CLI、
  Cherry Studio 和 TRAE CN。它们暂时还不能回传聊天，页面会如实说明，不再说"默认回传"。
- 自己登记的名字对上某个已知 agent 时，要你确认后才按那个 agent 对待：HelloOnce 不信 agent 自报的名字。
- **第一次导入快了很多。** 几个月的聊天改为并行、连续整理直到整理完，不再每 10 分钟只整理 20 段；导入期间删除的内容会立刻生效。

## 本机

- **重试真的会重试。** 没整理好的内容会从原来的任务接着整理；iMessage 不会再被一条空消息堵住；因账号余额不足失败的会直接说明。
- **系统权限。** 重试会打开系统设置里对应的列表（macOS 27 上也对），并给出添加 HelloOnce 的步骤。给了权限后，等这项权限的来源都会
  自己重新接上、警告自动消失；辅助功能不再重复弹窗。HelloOnce 的助手程序没有响应时，按钮照样打开系统设置；HelloOnce 本身没有响应时，
  页面会说"暂时没有响应"，不再误报"没能打开系统设置"。
- **电脑记录提前写好。** 打开页面时不会再满屏"正在整理中"。
- **添加手机**的窗口里 iPhone 和安卓并排，各有二维码和链接。

## 稳定性

- 调用模型时不再占着数据库：读取 HelloOnce 的 agent（比如每 15 分钟来查一次的个人 agent）启动时不会再因"数据库被锁"失败。
- 不同日子里属于同一个项目或同一门课的事件会连成一件事。

## 更新

已有用户可在设置里的「软件更新」检查新版本。首次安装请从 [0.1.21 公测发布页](https://github.com/FourthQuadrantInc/HelloOnce-Public-Beta/releases/tag/v0.1.21)
下载 `install.py` 和 `SHA256SUMS`。要指定这个版本，请给安装器传入 `--version v0.1.21`。
