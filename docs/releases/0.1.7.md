# friend. 0.1.7

## 0.1.7 revision 14 — friend. account, embeddings, platform connections

- **friend. account sign-in**: Settings → Model endpoints → Sign in, then confirm the code in your browser. Text, image, embedding and speech models are then provided by the account and usage is charged to its balance, with no endpoints or keys to enter. New accounts start with a welcome credit. Signing out restores your manual model configuration; without an account, manual configuration works as before.
- **Embeddings through the default relay**: one-click phone pairing now also configures an embedding model (qwen3-embedding-0.6b) unless you set your own.
- **Hosted platform connections**: Gmail, Outlook, GitHub, Google Calendar, Linear, Google Drive and Zoom, alongside Notion. Hosted connections appear in the platform section once the hosted connection service enables them.
- **Speech**: original audio is transcribed on the configured server; the 30-minute limit is removed.
- **Memories**: short card previews with full details folded; explicit model thinking mode.
- Revision 4 users can update in **Settings → Memory library → Software updates**. Revision 4 packages and the documents that changed remain attached with the `r4-` prefix.

## 0.1.7 revision 4 — Speech service moved to a new server

- The public speech service behind the default relay (one-click pairing) now runs on a new GPU server. Transcription and speaker labels (Person A / Person B…) behave as before.
- No change to the app's features, data or settings. Installed builds keep working without updating; revision 3 users can update in **Settings → Memory library → Software updates**.
- Rebuilt and smoke-tested on macOS arm64, Linux x86_64 and Windows x86_64. Documents, installer and the Android app are unchanged from revision 3; revision 3 archives remain attached with the `r3-` prefix.

## 0.1.7 revision 3 — Released connectors only

- The platform section now shows only completed built-in connections: currently Notion. Unavailable Gmail, Calendar, Drive, GitHub, Figma, Outlook and Zoom entries are hidden until their integrations ship.
- Fresh installations show **Notion → Connect**. Authorized installations show **Manage connection**, based on that installation's own local state. Installers do not contain another user's account, authorization, sync scope or memories.
- Existing source bridges remain manageable under Custom devices and platforms. Existing memories, original files, settings and Notion authorization are preserved.
- Revision 2 users can use **Settings → Memory library → Software updates** to update. Older builds can run the public installer once.

## Install or upgrade

Download install.py and SHA256SUMS, verify the installer hash, then run:

```sh
python3 install.py --version v0.1.7 --clients codex,claude --start --autostart
```

On Windows use py -3. Stop an older WebUI before replacing its executable. Keep your existing data directory and client configuration.

## Scope and limits

Notion reads only content granted by you and included in your sync scope. Search/index and API limits mean this is not a guaranteed complete workspace backup. Attachments are not downloaded; images/audio/video are not transcribed; unsupported blocks or properties are reported as incomplete. Disconnecting stops new reads and revokes the connection; saved memories remain.

Only Notion is currently shown as a built-in platform connection. Other platforms remain hidden until their account authorization and sync are ready. Existing external bridge registrations remain manageable under custom sources. See CONNECTORS.md and LANGUAGE.md below.

## Validation and distribution
