# friend. 0.1.7

## 0.1.7 修订版 14：friend. 账号、向量模型、平台连接

- **friend. 账号登录**：设置 → 模型接口 → 登录，在浏览器中确认代码。之后文本、看图、向量和语音模型由账号提供，按用量从余额扣费，不用填地址和 key。新账号附赠初始额度。退出登录恢复手动配置的模型；不登录时手动配置照常可用。
- **默认中转提供向量模型**：一键配对手机时，若你没有自己设置，会同时配好向量模型（qwen3-embedding-0.6b）。
- **托管平台连接**：在 Notion 之外，新增 Gmail、Outlook、GitHub、Google Calendar、Linear、Google Drive 和 Zoom。托管连接服务开通后才会出现在平台区。
- **语音**：原始音频在配置的服务器上转写，取消 30 分钟限制。
- **记忆**：卡片显示简短预览，完整内容折叠；模型思考模式可明确开关。
- 修订版 4 的用户可在**设置 → 记忆库 → 软件更新**中更新。修订版 4 的安装包和改动过的文档仍以 `r4-` 前缀附在发布页。

## 0.1.7 修订版 4：语音服务迁到新服务器

- 默认中转背后的公共转写服务（一键配对使用的那个）已迁移到新的 GPU 服务器，转写和说话人标注（人物A/人物B…）与之前一致。
- 应用功能、数据和设置没有变化，已安装版本无需更新即可继续使用；修订版 3 的用户可在**设置 → 记忆库 → 软件更新**中更新。
- 已在 macOS arm64、Linux x86_64 和 Windows x86_64 上重新构建并冒烟测试。文档、安装器和安卓 App 与修订版 3 相同；修订版 3 的压缩包仍以 `r3-` 前缀附在发布页。

## 0.1.7 修订版 3：只显示已上线的连接

- 平台区只显示已完成接入的内置连接，目前是 Notion。Gmail、日历、Drive、GitHub、Figma、Outlook 和 Zoom 在接入完成前隐藏。

- 已有的来源桥接仍在"自定义设备与平台"里管理。已有的记忆、原件、设置和 Notion 授权都保留。
- 修订版 2 的用户可在**设置 → 记忆库 → 软件更新**中更新；更早的版本运行一次公开安装器即可。

## 安装或升级

下载 install.py 和 SHA256SUMS，校验安装器的哈希，然后运行：

```sh
python3 install.py --version v0.1.7 --clients codex,claude --start --autostart
```

Windows 上用 py -3。替换可执行文件前先停掉旧的 WebUI。保留已有的数据目录和客户端配置。

## 范围与限制

Notion 只读取你授权并纳入同步范围的内容。受搜索/索引和 API 限制，这不是一份保证完整的工作区备份。附件不会下载；图片、音频、视频不会转写；不支持的块或属性会报告为不完整。断开会停止新的读取并撤销连接，已保存的记忆保留。

目前内置平台连接只显示 Notion。其他平台在账号授权和同步就绪前保持隐藏。已有的外部桥接注册仍在自定义来源里管理。见下方的 CONNECTORS.md 和 LANGUAGE.md。
