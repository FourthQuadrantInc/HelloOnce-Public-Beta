# Friend 0.1.8

Friend **0.1.8** brings Home and Records into one release. The old raw-memory page is replaced by information handoffs with floating details, generated language summaries, sources and later uses. Existing memories, originals, account settings and connections are retained.

> **Service status:** the account service is currently unreachable, so account sign-in, account models and hosted authorization wait for it to recover. Downloads and local installation do not depend on it; without signing in you can configure a working model endpoint yourself. This release does not claim the cloud service has recovered.

Extract the native program for your platform, or download `install.py` and `SHA256SUMS`, verify the installer, then run:

```sh
python3 install.py --version v0.1.8 --clients codex,claude --start --autostart
```

On Windows use `py -3`. The installer needs Python 3.9+; the extracted native program does not. See the [README](https://github.com/FourthQuadrantInc/HelloOnce-Public-Beta/blob/main/README.md) for the install prompt and guide. Public downloads need no access to the private source.

**What's new**

- Home manages the devices, platforms and apps actually connected; Records shows every information intake and handoff, each opening as a floating card.
- Friend generates and caches summaries for the language packs you enable; switching between English and Chinese reads the saved version. Internal summarizing is not recorded as a separate handoff.
- New-chat collection from Codex / Claude Code on a Mac can be turned on explicitly in each connection. Connecting over MCP does not by itself authorize collecting past chats.
- Long-file input budgets, splitting and repair are merged; originals are kept, and "received" is told apart from "turned into memories".
- Fixes Windows compatibility for saving originals, exporting and Chinese command-line output, keeping the guarantees not to overwrite existing files, to verify originals and to trace sources.
- Uses the full version number **0.1.8** with no r suffix; the internal manifest keeps revision 1 for older updaters.

**Upgrade and limits**

Before upgrading from 0.1.7 for the first time, back up your complete data directory: the old updater does not yet take the new version's full database snapshot. After upgrading, restart Codex/Claude; existing memories and connections carry over. Older memories without a handoff receipt are kept but are not turned into made-up handoffs.

The account service was unreachable from the test Mac during release preparation, so a fresh live account-model loop is not claimed as passed. Generated summaries require a working configured model service. Cached summaries and existing two-way sources were checked, and service errors show as failures. The separate Linux Mem0 chat pilot remains an explicit source installation with extra dependencies; it is not enabled in these standard packages. Native Windows chat-file collection is not supported; Windows MCP and Records remain available.

The Android demo is unchanged and remains in [v0.1.7](https://github.com/FourthQuadrantInc/HelloOnce-Public-Beta/releases/tag/v0.1.7). This release contains native executables, installer, public guides and checksums, not private source packages, credentials or user data.
