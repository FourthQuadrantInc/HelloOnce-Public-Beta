# Friend 0.1.8

Friend **0.1.8** 把首页和 Records 合进同一个版本。原来的原始记忆页换成信息交接记录，点开是悬浮详情，含按语言生成的摘要、来源和之后的使用。已有的记忆、原件、账号设置和连接都保留。

> **服务状态：** friend 账号服务当前无法连接，账号登录、账号模型及托管授权需要等待服务恢复。GitHub 下载和本机安装不依赖它；未登录时可单独配置可用的模型接口。本版不代表云端服务已恢复。

**下载**

- [Apple 芯片 Mac](https://github.com/FourthQuadrantInc/HelloOnce-Public-Beta/releases/download/v0.1.8/openworld-memory-v0.1.8-macos-arm64.tar.gz)：macOS 14+
- [Windows x64](https://github.com/FourthQuadrantInc/HelloOnce-Public-Beta/releases/download/v0.1.8/openworld-memory-v0.1.8-windows-x86_64.zip)：Windows 10/11
- [Linux x64](https://github.com/FourthQuadrantInc/HelloOnce-Public-Beta/releases/download/v0.1.8/openworld-memory-v0.1.8-linux-x86_64.tar.gz)：glibc 2.35+，如 Ubuntu 22.04+

可直接解压对应平台的独立程序，也可下载 `install.py` 与 `SHA256SUMS`，校验安装器后运行：

```sh
python3 install.py --version v0.1.8 --clients codex,claude --start --autostart
```

Windows 使用 `py -3`。安装脚本需要 Python 3.9+；解压后的独立程序不需要另装 Python。安装提示词与说明见[中文首页](https://github.com/FourthQuadrantInc/HelloOnce-Public-Beta/blob/main/README-zh.md)。公开下载不需要私有源码权限。

**本次更新**

- 首页统一管理实际连接的设备、平台和应用；Records 展示每次信息收入与支出，点开仍是悬浮卡片。
- Friend 按启用的语言包生成并缓存摘要，切换中英文读取已有版本。内部摘要处理不另记一笔交易。
- 可在各连接内明确开启 Mac Codex / Claude Code 的新聊天接收。MCP 接入本身不会自动授权历史聊天采集。
- 合并长文件输入预算、分片和修复；保留原件，并区分"已收到"和"转成记忆成功"。
- 修复 Windows 原件保存、导出和中文命令行输出的兼容性；保留不覆盖已有文件、校验原件和追溯来源的约束。
- 使用完整版本号 **0.1.8**，不再增加 r 后缀；内部清单保留 revision 1 以兼容旧更新器。

**升级与边界**

首次从 0.1.7 升级前，请完整备份本机数据目录；旧版更新器不会提前具备新版的完整数据库快照能力。升级后重启 Codex/Claude，已有记忆与连接继续沿用。缺少交接凭证的旧记忆保留，但不会凭空补成交易。

发布准备时，测试 Mac 无法访问账号服务的 HTTPS 和 SSH，因此**新增的真实账号模型闭环尚未验收通过**。模型摘要仍依赖可用的账号服务或用户配置的模型，不能把安装包测试通过等同于账号服务恢复。缓存摘要和已有双向溯源已检查；服务异常会显示失败状态。单独的 Linux Mem0 聊天试点仍需按源码另装、带额外依赖，标准安装包里没有启用。Windows 不支持原生采集聊天文件；Windows 上的 MCP 和 Records 照常可用。

安卓演示版没有变化，仍在 [v0.1.7](https://github.com/FourthQuadrantInc/HelloOnce-Public-Beta/releases/tag/v0.1.7)。本版包含原生可执行文件、安装器、公开说明和校验文件，不含私有源码包、凭据或用户数据。

**已验证的发布构建**

三个平台的原生 CI 全部通过：macOS/Linux 各 1,568 个源码测试，Windows 1,110 个；所有平台通过 109 个界面测试、安装包的上传/来源/手机/MCP 检查，以及更新器的备份、替换和重启检查。与系统无关的测试已跳过（macOS/Linux 1 个，Windows 43 个）。云端容器检查使用隔离的合成凭据。构建源码版本：`80ff4a2f643385d7c7c4025366419136e4b13e4a`。

公开发布后，macOS、Windows、Linux 均已从 GitHub 匿名下载、校验并成功安装，Codex/Claude 配置检查通过，无需私有仓库权限。
